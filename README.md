# Nostra – Fashion E-Commerce Website

A modern, responsive fashion e-commerce website built using **HTML, CSS, and JavaScript**. Nostra features a clean shopping interface with product categories, search, sorting, and a shopping bag.

## Features

- **Responsive Design:** Works on desktops, tablets, and mobile devices.
- **27 Different Products:** A collection of fashion items across multiple categories.
- **Product Categories:** Men, Women, and Accessories.
- **Product Search:** Search products by name.
- **Category Filters:** Browse products by category.
- **Price Sorting:** Sort products by price.
- **Shopping Bag:** Add products to the shopping bag and manage selections.
- **Product Images:** Online product images with fallback placeholders.
- **Modern Interface:** Clean layout, attractive banners, and a product showcase.
- **Interactive Carousel:** Promotional slides on the homepage.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Unsplash for online product imagery

## How to Run the Project

1. Download the project ZIP file.
2. Extract the ZIP file to your computer.
3. Open the extracted project folder.
4. Double-click `index.html` to open the website in your browser.
5. Ensure you have an internet connection for externally hosted product images.

For development, you can also open the project folder in Visual Studio Code and run it using the Live Server extension.

## Product Categories

- **Men:** Shirts, trousers, jackets, and jeans.
- **Women:** Blouses, dresses, pants, and cardigans.
- **Accessories:** Backpacks, crossbody bags, caps, and belts.

The website includes **27 products** in total.

## Customization

- Edit `index.html` to change the website content and page structure.
- Edit `style.css` to customize colors, fonts, layouts, and responsive styling.
- Edit `script.js` to update products, prices, search, filters, sorting, and shopping bag functionality.

## Limitations

- Product images are hosted externally and may require an internet connection.
- The shopping bag is a front-end demonstration.
- Online payments, order processing, user accounts, and backend inventory management are not configured.
