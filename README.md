# NOSTRA Storefront — image-fixed code
1. Extract this ZIP.
2. Keep `index.html`, `style.css`, and `script.js` together.
3. Open `index.html` in Chrome or use VS Code Live Server.
4. Internet access is required for the Unsplash photos and Google Fonts.

Includes a responsive storefront, 3-slide hero, category links/filters, product search and sorting, 15 products, cart totals stored in localStorage, newsletter demo, and automatic SVG fallback if a product image URL fails.

Note: the Unsplash images are loaded online. If your school/work network blocks image hosts, the product cards display the fallback instead. To use fully local images, download licensed photos into an `assets` folder and change `imgURL()` in `script.js`. Payment processing and real newsletter delivery are not connected.
